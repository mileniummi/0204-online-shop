## Функциональные:

- Юзер может получить список товаров
- Юзер может добавить товар в корзину
- Юзер может забронировать заказ
- Юзер может оформить доставку при бронировании заказа с возможностью уточнения времени доставки
- Юзер может удалить/добавить товар из уже оплаченной корзины, но после этого заказ будет заново забронирован
- Если юзер не оформил заказ через некоторое время, то ему через некоторое время придет уведомление о том что заказ не закончен
- Юзер должен оплатить заказ в течении определенного времени, иначе заказ будет аннулирован
- Если доставка не была выполнена вовремя или из-за ошибки во время бронирования, то производится возврат средств

## Нефункциональные:

- Масштабируемость - ПО должно быть пригодно для быстрой модификации, добавления нового функционала
- Надежность - реализация "fault-tolerant" системы, то есть приложение должно быть готово обрабатывать различное поведение внешней системы, включая частичную и полную недоступность, увеличение времени отклика и тд.
- Доступность - степень готовности продукта или сервиса к эксплуатации по требованию
- Поддерживаемость - ведение полной истории обращений к внешней системе, обязательно включающее результаты обращения, длительность и уникальный id операции, который генерирует внешняя система при обращении. Это процесс мониторинга системы, ее улучшения, оптимизации и устранения дефектов после передачи в эксплуатацию.
- Производительность - сбор статистики приложения, ее визуализация, анализ метрик и изменение распределения мощностей для разных систем
